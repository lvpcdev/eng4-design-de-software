# ADR-0001: Reestruturação do Projeto

## Status
Proposto

## Contexto
O código original da empresa Andrades's Corp foi avaliado como obsoleto devido a uma implementação mal efetuada, gerando dificuldades para ampliar e manter o código além de uma documentação desorganizada que dificulta o processo do futuro da empresa.

## Decisão

Vamos refazer o código do sistema gradualmente, utilizaremos processos de refatoração, como a remoção de duplicação, simplificação de lógica condicional e clarificação de código sem prejudicar o sistema com uma estrutura que facilite atualizações futuras, assim será possível documentar e manter o código do sistema, melhorando principalmente a coesão.

## Alternativas Consideradas

- **Treinamento da equipe diante do código atual**: descartado pois mesmo a equipe treinada com o código obsoleto acarretará problemas futuros como incapacidade da resolução de problemas modernos e a implementação de novas funcionalidades, sendo necessário atualizar o código legado por questões de escalabilidade e desempenho.

## Consequências

- O código ficará mais organizado e legível para realizar manutenções futuras no sistema como implementações novas e correções de erros.
- Aumento da produtividade da equipe devido a melhor clareza da documentação e código.
- Deverá ser realizado um novo treinamento contendo a explicação perante a nova linguagem de programação e padrão de projetos que deverá ser implementado.
