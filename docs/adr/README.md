# Design de Software: ADRs.

## Pasta ADR:
 A pasta **ADR** tem como objetivo armazenar todos os *Architecture Decision Records* (ADRs) utilizadas para o aprimoramento do software.  Esses documentos registram as principais decisões arquiteturais tomadas durante o desenvolvimento do software, servindo como um histórico para facilitar a compreensão, manutenção e evolução do sistema.
 
## O que é uma ADR? 

 Uma ADR (Architecture Decision Record) é um documento curto que registra uma decisão importante de arquitetura tomada durante o desenvolvimento  de um sistema. Seu objetivo é documentar o contexto da decisão, a solução adotada e as consequências dessa escolha, facilitando o entendimento do projeto por toda a equipe.



## Estrutura de uma ADR: 

Título -> Status -> Contexto -> Decisão -> Consequências
